# Restaurant Template: "The Copper Fig"

A warm, editorial one-page site for a bistro, cafe, wine bar, or any restaurant that wants to feel considered rather than corporate.

**Design:** dark ink hero with a film-grain texture, cream body sections, copper accents, Fraunces serif display type paired with Karla. The menu uses classic dotted price leaders.

**Sections:** sticky nav, hero with reservation CTA, story/about, full menu (small plates, wood oven, pasta, sweets), hours and location, reservation call-to-action, footer. Includes Restaurant JSON-LD structured data for local SEO.

**No photos required to look finished.** Image slots are decorative CSS blocks marked with `<!-- IMAGE SLOT -->` comments; swap them for `<img>` tags whenever you have real photos.

**Customize in 10 minutes:**
1. Open `index.html` in any text editor.
2. Search for "Copper Fig" and replace with your restaurant name.
3. Edit the menu items, prices, hours, address, and phone number (search for `555`).
4. Colors and fonts live in the small `tailwind.config` block near the top of the file.
