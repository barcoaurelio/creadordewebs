# 🦷 32 Smile – Dental Clinic Frontend Website

A clean, modern, and responsive **dental clinic landing page** built using **HTML, CSS, and JavaScript**. This project was independently developed to showcase frontend skills with a strong emphasis on layout design, responsiveness, and user experience.

---

## 📌 Overview

**32 Smile** is a static website designed for a fictional dental care clinic. The layout includes a hero section, services, testimonials, contact form, and footer—all styled for a professional healthcare presentation. Perfect as a frontend template for clinics, medical startups, or portfolio showcases.

---

## 🛠️ Tech Stack

- **Frontend**:  
  `HTML5`, `CSS3`, `JavaScript (Vanilla)`
- **Design Principles**:  
  Mobile-first responsiveness, clean UI, intuitive layout

---

## ✨ Features

- ✅ Fully responsive layout (desktop, tablet, mobile)
- ✅ Professional dental clinic theme
- ✅ Clean and modern UI/UX
- ✅ Custom contact form UI
- ✅ Animated scroll effects (optional)
- ✅ SEO-friendly structure with semantic HTML
