# Free Small Business Website Templates (2026)

Four clean, responsive, single-file HTML website templates for small businesses. No build step, no frameworks to install, no lorem ipsum. Open the file, change the text, put it online.

Each template is one `index.html` using [Tailwind CSS](https://tailwindcss.com) via CDN and Google Fonts. Everything else (styles, icons, structured data, mobile menu) is inside the file.

## How to use

Honest version: this takes about 10 minutes and no coding knowledge beyond "edit text and save".

1. **Download** a template folder (or clone the repo, or use "Code > Download ZIP").
2. **Open `index.html` in your browser** by double-clicking it. That is the whole preview workflow.
3. **Edit the text** in any editor (VS Code, Notepad, TextEdit in plain-text mode). Replace the business name, menu/services, prices, address, and phone number. Each folder's README lists exactly what to search for.
4. **Change colors and fonts** in the small `tailwind.config` block near the top of the file. One hex value re-themes most of the page.
5. **Deploy anywhere.** It is a single static file, so any of these work free:
   - [Netlify Drop](https://app.netlify.com/drop): drag the folder into the browser, done
   - [GitHub Pages](https://pages.github.com/): push the folder, enable Pages
   - [Vercel](https://vercel.com), [Cloudflare Pages](https://pages.cloudflare.com/), or plain shared hosting via FTP

One note: the templates load Tailwind and fonts from CDNs, so viewers need an internet connection (true for any live website anyway).
